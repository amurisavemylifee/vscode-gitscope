# GitScope

Расширение VS Code для работы с git. Первая функция — сравнение **состояний кода**
в любых двух точках истории: выбираете две ревизии (ветки, теги, коммиты) и видите,
чем отличается дерево файлов, как во вкладке «Files changed» у pull request.

Сравнение выполняется как `git diff <base> <compare>` — двухточечное, дерево против
дерева. Это отличается от того, что GitHub показывает в PR (там трёхточечное, от точки
расхождения): GitScope честно показывает **всю** разницу между двумя снимками кода,
включая изменения, которые попали в базовую ветку после ветвления.

## Разработка

```bash
pnpm install
pnpm build          # разовая сборка extension host + webview
pnpm typecheck      # tsc по обоим проектам
pnpm test           # unit + integration (Vitest)
pnpm test:e2e       # e2e в настоящем VS Code (на headless-машине под xvfb-run)
```

Отладка: открыть папку в VS Code и нажать **F5** — поднимется Extension Development
Host со сборкой в watch-режиме. Команда в палитре: **GitScope: Сравнить ревизии…**

## Устройство

Слои разложены так, чтобы будущие git-функции переиспользовали нижние два:

| Слой | Зависит от | Назначение |
|---|---|---|
| `src/shared/` | ничего | Модель данных, протокол webview ⇄ host, RPC. Изоморфный: работает и в Node, и в браузере |
| `src/core/` | Node | Запуск `git` и разбор его вывода. Про `vscode` не знает, тестируется обычным Vitest |
| `src/services/` | `core` + `vscode` | Репозитории воркспейса, ревизии, сравнения, настройки |
| `src/features/` | всё выше | Команды, пикеры, webview-панели |
| `webview/` | `src/shared/` | React-приложение панели |
